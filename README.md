Instructions  

1 - Install Visual Studio Code.  

2 - Install the C++ extension for VS Code. You can install the C/C++ extension by searching for 'c++' in the Extensions view (Ctrl+Shift+X).  

3 - run these commands in terminal  

sudo apt update && sudo apt install build-essential gdb  

sudo apt-get install build-essential gdb  

mkdir projects  

cd projects  

mkdir helloworld  

cd helloworld  

4 - Login to Git (you can use gh auth login)  

5 - Clone the git repo (git clone URL)  

6 - Run the code with 2 lines of code  

g++ -Wall helloWorld.cpp -o my_program  

./my_program
